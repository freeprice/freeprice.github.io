# Чат-бот IRC на PHP
Чат-бот на PHP для протокола IRC, который превращает класс в интерактивную викторину:
учитель составляет тесты прямо в чате, ученики проходят их в диалоге с ботом, а оценки выставляются автоматически.

## О проекте
**PHP-IRC-Bot** — учебный проект, разработанный для школьного класса. Бот подключается к IRC-каналу класса и выполняет две роли:

- **для учителя** — конструктор тестов прямо из чата: вопросы четырёх типов (одиночный выбор, множественный выбор, ввод текста, соответствие), автоматическая проверка и выставление оценок;
- **для учеников** — прохождение тестов в дружелюбном диалоге: бот задаёт вопросы по одному, принимает ответы, сразу показывает результат.

Проект написан как пример реальной клиент-серверной разработки: работа с сокетами, протоколом RFC 2812, и обработкой пользовательского ввода.
## Возможности

**Учитель:**
- создание, редактирование и удаление тестов командами прямо в IRC-чате;
- четыре типа вопросов: одиночный выбор, несколько правильных ответов, свободный ввод (с учётом регистра — на выбор), соответствие;
- настройка шкалы оценивания и времени на прохождение;
- экспорт результатов в CSV / электронный журнал.

**Ученик:**
- прохождение тестов в пошаговом диалоге;
- мгновенная обратная связь: результат, оценка и разбор ошибок;
- история своих прохождений по команде `*result`.
## Установка
### Требования
- PHP 8.1 или новее
- доступ к IRC-серверу (подойдёт локальный [Ergo](https://ergo.chat/) или классный сервер для тестов);
